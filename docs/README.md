## 🏆 Projet Mabutu

**Contexte :** Projet DEV Learn IT B3  
**Objectif :** Création d'une application de blog complète  
**Technologies :** React + Django + Base de données + Documentation  
**Date de soutenance :** 13 mai 2025  

### Fonctionnalités principales

✅ **Authentification des utilisateurs**
- Inscription et connexion
- Gestion des profils
- Autorisation basée sur les rôles

✅ **Gestion des posts**
- Création de posts (administrateurs uniquement)
- Affichage public des posts
- Prévisualisation limitée (5 lignes)
- Vue complète en modal ou nouvel onglet

✅ **Système de commentaires**
- Commentaires pour utilisateurs connectés
- Pagination (5 commentaires par page)
- Affichage complet dans la vue détaillée

✅ **Réactions emoji**
- Système de réactions pour utilisateurs connectés
- Compteur de réactions
- Gestion des réactions multiples

✅ **Interface responsive**
- Design avec Tailwind CSS
- Navigation intuitive
- Expérience utilisateur optimisée
